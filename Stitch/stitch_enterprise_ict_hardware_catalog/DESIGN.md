## Brand & Style

This design system embodies an uncompromising engineering-grade ethos tailored for enterprise B2B ICT infrastructure, telecommunications cabling, and data center hardware procurement. The visual narrative is built around precision, technical competence, and architectural rigor. Rather than generic corporate SaaS tropes, it projects the authority of industrial specification sheets combined with the clarity of state-of-the-art developer environments.

The target audience comprises enterprise infrastructure architects, systems integrators, network engineers, and procurement directors who value functional density, rapid scanning, clear technical parameters, and zero ambiguity. 

The aesthetic is Modern Technical Precision—characterized by:
- Pure optical white (#FFFFFF) working planes contrasted against calibrated cool slate foundations (#F8FAFC, #F1F5F9).
- Surgical hairline borders (#E2E8F0) that enforce strict modular alignment.
- High-contrast cobalt blue accents communicating confidence and active signaling.
- Monospace engineering micro-data blocks and technical specs that present complex serial numbers, bandwidth ratings, and pin configurations with absolute clarity.

## Colors

The palette is engineered specifically for high-legibility light mode environments, minimizing cognitive fatigue over sustained enterprise workflows while emphasizing technical hierarchy:

- **Primary Canvas & Surfaces**: Crisp Pure White (`#FFFFFF`) forms the foundational layer for product showcases and editable forms. Layer 1 surfaces (`#F8FAFC`) establish structural panels, side navigation, and inactive card backgrounds. Layer 2 surfaces (`#F1F5F9`) define interactive toolbars, table headers, and nested spec containers.
- **Primary Brand Cobalt (`#1D4ED8`) & Active Blue (`#2563EB`)**: Anchor primary interactive states, key actions, high-priority links, and selection rings.
- **Secondary Cyan Engineering (`#0891B2`)**: Reserved for engineering metadata, technical certifications (e.g., Cat6A, OM4, PoE++), compliance chips, and data-density accents.
- **Neutral Typography Core (`#0F172A`)**: Obsidian Slate provides near-black contrast without harshness. Secondary text resolves at `#475569`, with muted technical metadata at `#64748B`.
- **System Borders & Dividers (`#E2E8F0`)**: Hairline dividers construct the grid geometry. Interactive borders on hover transition cleanly to `#CBD5E1` or cobalt focus rings.
- **Feedback Accents**: Operational Emerald (`#059669`) for in-stock and validation states, Alert Amber (`#D97706`) for low-stock or lead-time warnings, and Precision Crimson (`#DC2626`) for spec discrepancies or critical alerts.

## Typography

The typographic hierarchy implements an intentional split: **Geist** handles the structural communication, product nomenclature, and narrative body copy, while **JetBrains Mono** delivers machine-level data, standard product SKUs, optical fiber tolerances, electrical ratings, and system statuses.

Key implementation rules:
- Technical serial numbers, part codes (e.g., `YFC-CAT6A-STP-BLU`), patch panel port assignments, and pinouts must strictly use `label-md` or `label-sm` with JetBrains Mono.
- Numeric metrics (bandwidth in MHz, attenuation in dB, physical gauge in AWG) must leverage tabular figures (`tnum`) in JetBrains Mono to facilitate instant column-to-column vertical comparison.
- Headings maintain tight letter-spacing to reinforce architectural density, while body copy preserves an open line-height to guarantee legibility across dense spec sheets and parameter tables.

## Layout & Spacing

This design system adheres to a disciplined 4px / 8px baseline rhythm structured around a 12-column responsive fluid grid:

- **Desktop (1280px+)**: 12-column layout with 24px (`gutter-lg`) gutters and 40px (`margin-lg`) outer framing margins. Max inner container width caps at 1440px to prevent extended line lengths in wide-screen enterprise environments.
- **Tablet (768px - 1279px)**: 8-column layout with 16px (`gutter`) gutters and 24px (`margin-md`) margins. Hardware filter sidebars collapse into a slide-over panel.
- **Mobile (< 768px)**: 4-column layout with 16px gutters and 16px (`margin`) edge margins. Complex multi-column spec sheets reflow into vertically stacked key-value blocks.

Component spacing preserves strict compact efficiency: table cell vertical padding stays locked to `space-sm` (8px), card internals to `space-md` (16px), and high-level section transitions to `space-xl` (32px) or `space-2xl` (48px).

## Elevation & Depth

Visual hierarchy relies on crisp architectural surface layering and low-contrast borders rather than heavy atmospheric drop shadows:

- **Base Ground**: Surface White (`#FFFFFF`) with `#E2E8F0` hairline strokes for static containers.
- **Level 1 (Subtle Lift / Interactive Hover)**: Surfaces rise through a precise dual boundary: a 1px border (`#CBD5E1`) paired with an ultra-subtle directional shadow: `0 1px 3px rgba(15, 23, 42, 0.05), 0 1px 2px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Popovers, Spec Flyouts, Dropdowns)**: Elevated panels use Surface White (`#FFFFFF`), a distinct stroke (`#E2E8F0`), and an architectural cast: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
- **Level 3 (Modals & Command Palettes)**: Overlay panels sit above an obsidian backdrop blur (`rgba(15, 23, 42, 0.4)` with 4px backdrop blur), framed with `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The system enforces a **Soft (`1`)** shape language that reflects engineered metalwork and industrial rack equipment. Roundedness is restrained to deliver a crisp, professional posture:

- **Base Components (Buttons, Input fields, Badges, Chips)**: `0.25rem` (4px). Avoids sterile sharp corners while preserving high rectangular density.
- **Group Containers (Hardware Cards, Data Sheets, Modals)**: `0.5rem` (8px) using `rounded-lg`.
- **Micro UI (Pill indicator lights, Pin badges, Tab dots)**: Restricted strictly to functional circle geometry (50%) for state status lamps (e.g., active link indicators).

## Components

### Buttons
- **Primary**: Background `#1D4ED8`, text `#FFFFFF`, border none, 4px corner radius. Hover transitions to `#1E40AF`. Active to `#1E3A8A`. Focus ring is 2px `#2563EB` offset by 2px white.
- **Secondary / Spec Action**: Background `#FFFFFF`, text `#0F172A`, 1px border `#E2E8F0`. Hover uses `#F8FAFC` and border `#CBD5E1`.
- **Engineering / Ghost**: Text `#1D4ED8`, background transparent, hover `#EFF6FF`.
- Typography is Geist `title-sm` (14px, SemiBold).

### Engineering Badges & Chips
- **Category & Compliance Badges**: JetBrains Mono `label-sm`. Background `#ECFEFF` with text `#0891B2` and 1px border `#CFFAFE` for technical protocols (e.g., `RoHS`, `Cat6A`, `SFP+`, `LSZH`).
- **Status Filter Chips**: 4px radius. Inactive: `#F1F5F9` background, `#475569` text. Active: `#1D4ED8` background, `#FFFFFF` text.

### Hardware Catalog Cards
- Background `#FFFFFF` framed by a 1px `#E2E8F0` border and 8px border radius.
- Padding is structured with an internal image stage (`#F8FAFC` background, 4px radius), followed by a 16px body container featuring product title, monospace SKU line, key performance parameters table, and clear RFQ (Request for Quote) / Datasheet download actions.
- Hover effect transitions border to `#2563EB` and applies Level 1 subtle elevation.

### Data Tables & Spec Matrices
- Alternating subtle rows or clean white with 1px `#E2E8F0` dividers. Table headers set to `#F8FAFC`, Geist `title-sm` with `#475569` label color.
- Data cells utilize JetBrains Mono `body-sm` for aligned numeric specs (dB, MHz, mm, AWG). Compact row height (36px–40px) enables dense comparative engineering analysis.

### Form Inputs & Search
- Inputs set to `#FFFFFF` background, 1px border `#E2E8F0`, 4px radius, 14px Geist text. 
- Prefix slots house JetBrains Mono SKU search triggers or optical filter icons in `#64748B`. Focused state locks to `#FFFFFF` with a 1px `#1D4ED8` border and an adjacent 3px focus haze (`rgba(29, 78, 216, 0.12)`).

### Selection Controls
- **Checkboxes & Radios**: 16px square/circle with 1px border `#CBD5E1`. Checked state fills `#1D4ED8` with a crisp white tick/dot. High visual clarity for multi-parameter faceted hardware filters.
